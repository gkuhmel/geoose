# Geoose — notes pour Claude Code

Jeu de géo pour Nils (enfant). Interface en français, ton ludique, cible **iPhone et iPad via Safari** (aussi publié comme artifact claude.ai : tout doit tenir dans `dist/index.html`, aucun fetch réseau).

## Stack
- Vite + JS vanilla (pas de framework), `vite-plugin-singlefile` pour un build en un seul HTML.
- Déploiement Cloudflare Workers (assets statiques) : `wrangler.jsonc` → `dist/`, `npm run deploy` (= `vite build && wrangler deploy`).
- `topojson-simplify` : niveaux de détail du dessin.
- `d3` (projection Mercator, zoom/pan via `d3.zoom`, géodésie `geoDistance`/`geoContains`), `topojson-client`, carte `world-atlas/countries-50m.json` (Antarctique retirée).
- Police Google Fonts « Baloo 2 » (seule ressource externe).

## Fichiers
- `index.html` : markup (HUD, carte SVG, écrans accueil / fin).
- `src/style.css` : styles (glassmorphism, animations, media query ≥ 700px pour iPad).
- **Thèmes** (⚙️ Réglages, `geoose-theme`, liste `THEMES`) : Atlas (défaut, clair pastel), Néon (nuit, contours lumineux), Vieille carte (parchemin, sépia, Georgia), Bonbon (rose guimauve), Jungle (fleuves turquoise, terres vertes), Banquise (mer polaire, terres de glace), Volcan (roche sombre, côtes de lave). Toutes les couleurs passent par des variables CSS (`:root`, puis `:root[data-theme="…"]` en fin de `style.css`) ; ne pas remettre de couleur en dur. Les pays ont une classe `c0…c6` → `--l0…--l6` (aucun redessin au changement de thème). Pas de `filter` CSS sur la carte (perf) : la lueur du Néon vient des halos existants.
- `src/countries.js` : les 197 pays — `[nom, article, capitale, lat, lon, iso numérique world-atlas, iso alpha-2, renommée pays, renommée capitale, renommée drapeau]`. Renommée 1 (célèbre) → 4 (rareté) = niveau de difficulté, **par mode**. L'alpha-2 sert au drapeau emoji. Ids spéciaux : Kosovo = `XK` (assigné dans `main.js`, sans id dans world-atlas), Tuvalu absent de la carte 50m → distance à la capitale.
- Niveaux : un niveau tire les questions dont la renommée **égale** le niveau (complète avec les niveaux voisins s'il en manque), pas un volume cumulatif.
- `src/cities.js` : mode **Villes** — 146 grandes villes qui ne sont pas des capitales, `[nom, iso pays, lat, lon, renommée 1-4]`, id `iso:nom`. Hong Kong / Macao rattachés à la Chine dans la carte. 14 villes côtières tombent en mer sur la carte 50m : d'où la tolérance « ≤ 50 km de la ville = réussi ».
- Barème (`scoreRec`) : pays / drapeau = distance à la frontière ; **capitale / ville = tous les points dans le bon pays** (ou ≤ 50 km de la ville), sinon points selon la distance au pays ; `dT` = distance à la ville (affichage), `perfect` = pile dessus (confettis).
- Apprentissage : clés `type|iso` (ou `ville|iso:nom`) dans `localStorage["geoose-revisions"]` ; ajout si raté (indice, ou > 150 km de la frontière pour pays/drapeau, ou hors du bon pays pour capitale/ville), retrait si réussi. 
- `src/main.js` : tout le jeu (carte, gestes, manches, tours à deux, score, chrono, passeport, confettis).
- `src/facts.js` : « Le savais-tu ? », une info par pays (clé alpha-2), affichée après chaque réponse (🔊 pour l'écouter).
- `src/audio.js` : sons synthétisés en WebAudio (aucun fichier) + voix (`speechSynthesis`, fr-FR). Deux réglages : sons (`geoose-son`) et lecture auto des noms (`geoose-voix`, **désactivée par défaut**) ; le 🔊 du « Le savais-tu ? » lit toujours. iOS : `unlock()` au premier toucher.
- `public/` : `manifest.webmanifest`, `sw.js` (hors ligne : page réseau d'abord, reste cache d'abord), `icons/` (générées depuis le dessin de l'oie), `_headers` (Cloudflare). Le SW ne s'enregistre qu'en https hors iframe ; dans l'artifact claude.ai, les liens manifeste/icônes ne se chargent simplement pas.
- Continents : lignes `"@europe"`… dans `countries.js` ; `CONTINENTS` donne nom, emoji et cadrage de départ (`homeView`).
- Passeport : `localStorage["geoose-passeport"]` = `{iso: [types réussis, 4 possibles dont ville]}` (+ `-dates` : date du 1er tampon) ; tampon quand une question est réussie (même règle que les révisions). `stampSVG` dessine le tampon (anneau à l'encre du continent, nom en arc, drapeau, ★ par mode, date, rotation fixe par pays) ; il s'abat aussi sur la carte de résultat (`#rstamp`). Le panneau passeport a une hauteur fixe : seul `#pgrid` défile (sinon iOS écrase les onglets).
- Deux joueurs : même question pour les deux, chacun pose son oie à son tour (`submitTurn`), révélation après le 2e (`reveal`). Oie blanche / cendrée (`PLUME`), couleurs `PCOL`. Révisions et passeport ne suivent que le joueur 1 ; pas de record à deux.
- Options et prénoms mémorisés (`geoose-options`, `geoose-noms`).
- `src/islands.js` : mode **Îles** (type `ile`) — 37 îles `[emoji, nom avec article, pays, lat, lon, rayon km, renommée, le savais-tu]`. Barème **par rayon** (`zoneOf` = cercle géodésique) : dans la zone = tous les points, sinon selon la distance à la zone (le bon pays ne suffit pas : la Corse ≠ toute la France). Zone dessinée (`.zone`), pas de surbrillance du pays, info propre à l'île. Médaille « Robinson » (10 îles).
- **Zone France** (`opts.mode="france"`, sous-mode `opts.frmode` = `dept` | `villefr`, choisi à l'étape 2 de l'assistant ; hors mélange et défi) : `src/france.js` (préfectures + renommée des 96 départements de métropole, 82 villes françaises avec infos) et `src/data/departements.json` (TopoJSON quantifié ~57 Ko, IGN Admin Express, Licence ouverte — reconstruit par `scripts/build-departements.mjs`, qui remet aussi les contours dans le sens attendu par d3). Contours dessinés seulement pendant une question France (`#map.fr .dept`). Barème : département = tous les points dedans ; ville = tous les points dans son département (ou ≤ 15 km) ; distance décroissant vite (`FR_SCALE` 150 km au lieu de 1 200). Cadrage avec marge et zoom adaptés (`frameBox(..., maxK, pad)`, `quizBox`), zoom max ×150. Survol du département sous l'oie, anneau pour Paris. Médaille « Tour de France » (20 trouvés).
- `src/monuments.js` : mode **Merveilles** (type `monument`) — monuments, sites et animaux `[emoji, nom avec article, isos acceptés séparés par |, lat, lon, renommée, "m"|"a"]` ; barème comme capitale/ville (n'importe lequel des pays acceptés = tous les points). Pas de tampon au passeport.
- **Partie** (`opts.chrono`) : 0 calme, 1 chrono, 2 **survie** (3 vies, liste rallongée à la volée, +1 niveau toutes les 5 réussites, record = bonnes réponses), 3 **quiz** (mode inversé : pays allumé / point montré, 4 propositions du même type et du même continent, `startQuiz`, carte non cliquable). Survie et quiz : solo.
- **Défi du jour** (`startGame("defi")`) : 5 questions (une par type) tirées avec `seededRng(date locale)`, identiques pour tous le même jour ; série de jours dans `geoose-defi` (`finishDefi`).
- `src/progress.js` : XP / niveaux (`geoose-xp`, palier 80 + 40×(n-1)), médailles (`MEDALS`, `award`, `geoose-medailles`), statistiques pour le tableau de bord (`geoose-stats` : temps par jour, réussite par mode, erreurs fréquentes, confusions « pays visé > pays touché »), défi.
- `src/goose.js` : dessin SVG de l'oie (`gooseParts`, `gooseSVG`) ; **9 plumages** (`PLUMES` : blanche, cendrée niv. 5, puis une oie par continent complet au passeport — royale, girafe, panda, toucan, récif — + dorée (défi 7 jours) et cosmique (197 pays)) ; **46 accessoires** sur 7 emplacements (tête, yeux, bec, cou, dos, pattes, objet tenu), débloqués par niveau (`unlock:{lvl}`) ou par médaille (`unlock:{medal}`, `isUnlocked`). Choix dans `geoose-oie` (`plume` + un id par emplacement), porté par l'oie du joueur 1 ; le joueur 2 garde l'oie cendrée (ou blanche si le 1 l'a prise). Les nouveautés débloquées sont annoncées (toast + fin de partie).
- Écrans : **Mon oie** (`#oie`), **Progrès** (`#progres` : médailles + tableau de bord parent), **Réglages** (`#reglages` : sons, voix, thème). Animations : salto de l'oie sur un atterrissage parfait (`.goose.flip`), danse en fin de partie réussie ou montée de niveau (`.goosesvg.dance`).
- **Navigation** : splash (`#splash`, globe orthographique en canvas qui tourne + l'oie en orbite, ~2,6 s ou un toucher ; `?nosplash` dans l'URL le saute pour les tests) → **menu** (`#home` : en-tête oie + niveau + série, ⚙️ ; 4 grosses actions : Rejouer comme la dernière fois / Jouer tout de suite (`#replaybtn`, résumé `optsSummary`), Nouvelle partie, Défi du jour, Réviser mes erreurs) + **barre d'onglets** (`#tabbar` : Jouer · Passeport · Progrès · Mon oie, `openTab`). Nouvelle partie = **assistant pas à pas** (`#wizard`, `showStep` : quoi → où → niveau → comment, un choix fait avancer tout seul). Classes `body.splash / .wiz / .ingame / .pmap` : masquent onglets et interface de jeu hors contexte.
- Rien ne doit défiler sur le menu ni l'assistant : vérifier que `.homewrap` et `.wizwrap` tiennent dans `innerHeight` (iPhone SE 375×548, iPhone 390×664, iPad paysage 1180×760), y compris l'étape 4 « à deux » (prénoms).
- Carte du passeport (`openPassMap`) : pays tamponnés coloriés au pastel du continent (`PASTEL`, `style.fill` qui prime sur l'attribut), autres grisés ; HUD masqué (`body.pmap`) ; un tap sur un pays (`passMapTap` → `countryAt`) montre son tampon.

## Points d'attention
- Gestes (façon GeoGuessr / Plans) : **tap simple** (< 12 px, < 500 ms) pose ou déplace l'oie, **Valider** confirme ; un glissement > 12 px est un pan. Appui sur l'oie (`.pin-hit`, r=34) + glisser = ajustement fin : son ombre (`.shadow`, point exact d'atterrissage) se place `LIFT` (60 px) au-dessus du doigt et l'oie s'envole au-dessus d'elle en battant des ailes (`.fly`, `.wing`, classe `#map.dragging`), et `zoom.filter` bloque le pan pendant ce temps. Détection maison via pointer events.
- Pays-réponse surligné sur un calque à part en **géométrie exacte** (`gTgt`, `setTarget`) : dans la carte simplifiée (LOD), les micro-États (Singapour, Bahreïn, Vatican, Monaco…) font 0 px. Les pays minuscules (`tinyIso`) reçoivent en plus un anneau pointillé (`.tinyring`), au quiz et après la réponse.
- Après **chaque** réponse (tous modes), une **fiche** sur la carte : drapeau + pays + 🏛️ capitale (+ 🏙️ ville / merveille), taille constante quel que soit le zoom. `cardOf` la mesure ; après le recadrage (`frameBox` renvoie la transformation et la zone visible), `game.cardPos` la place sous la cible, au-dessus si elle sortirait en bas, et la décale pour éviter les bords et la colonne des boutons de zoom. Au quiz, la révélation garde le cadrage de la question (`quizBox`).
- Modes pays / drapeau : le pays sous l'oie est surligné (`gHover`, `countryAt` = bbox puis `geoContains`), sans afficher son nom.
- Les écrans masqués (`.screen.hidden`) doivent rester `visibility:hidden` + `pointer-events:none` sur les enfants, sinon leurs boutons invisibles bloquent la carte (bug déjà rencontré).
- Les marqueurs (oie, cible) sont en coordonnées carte avec `scale(1/k)` mis à jour au zoom (`placeMarkers`), sans les recréer (sinon les animations CSS rejouent).
- Épaisseurs de traits : `calc(Npx / var(--k))` sur le groupe racine.
- Bords de carte : `zoom.constrain(constrainView)` laisse glisser la carte jusqu'à ce que son bord atteigne ~45 % de l'écran (`EDGE`), pour centrer un pays en bout de carte (Nouvelle-Zélande, Alaska…).
- **Perf carte** (le pan saccadait) : le coût est le raster SVG, surtout les halos côtiers (gros traits). Donc :
  dessin en géométrie simplifiée selon le zoom (`lodFor`, 3 niveaux, changés à la fin du geste, en cache),
  halos sur un contour très simplifié, halos et côtes découpés en tuiles de 30° (culling hors écran),
  `onZoom` ne fait rien d'autre que le `transform` quand k ne change pas (simple glissement).
  Le gameplay (`byIso`, `geoContains`, distances) garde la géométrie 50m exacte.
  Mesurer avec une trace Chromium (somme des `RasterTask`) plutôt qu'un compteur rAF, qui ne voit rien en headless.
- Tester en 390×844 (iPhone) et 820×1180 / 1180×820 (iPad), avec événements tactiles.
